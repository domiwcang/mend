mend applies an edit that an AI model wrote to a tree of text files — unified diffs (often with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON text-editor tool calls — finding the lines each edit names at the first of three matching tiers, and writing every change or none. Node 22, standard library only. See SPEC.md for the whole contract.

## Run it

```sh
node main.ts [options] [PATCH]
```
